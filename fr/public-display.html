Affichage public

Les représentations textuelles peuvent être affichées sur les pages publiques des médias d’un site à l’aide d’un bloc de page de ressource.

Bloc de page de ressource

Media Text fournit un bloc de page de ressource nommé Représentations textuelles en texte brut, compatible avec les pages de médias.

Pour l’ajouter :

  1. Dans l’interface d’administration, modifiez le site, et allez dans Thème (ou Pages de ressource, selon le thème et la version d’Omeka S).

  2. Dans la configuration de la page des médias, ajoutez le bloc Représentations textuelles en texte brut à une région.

  3. Enregistrez.

Voir Configurer les pages de ressource dans le manuel utilisateur d’Omeka S (en anglais).

Le bloc affiche, pour chaque représentation textuelle du média visible par le visiteur (voir Visibilité), son titre et son contenu converti en texte brut (voir Formats). Rien n’est affiché si le média n’a aucune représentation textuelle visible.

Mise en forme

Le bloc est rendu sous forme de liste de définitions HTML :

<dl class="mediatext-text">
    <div class="property">
        <dt>Title of the representation</dt>
        <dd class="value">Content as plain text</dd>
    </div>
    ...
</dl>

La feuille de style du module (asset/css/mediatext-site.css) préserve les retours à la ligne du texte. Elle peut être surchargée dans le thème.
