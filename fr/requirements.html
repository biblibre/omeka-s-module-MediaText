Prérequis

  • Omeka S ≥ 4.2.0

  • Extension PHP zlib

Si l’extraction automatique du texte est nécessaire, les programmes suivants sont requis :

  • pdftotext (pour les fichiers .pdf)

  • odt2txt (pour les fichiers .odt)

  • docx2txt (pour les fichiers .docx)

  • catdoc (pour les fichiers .doc)

  • tesseract (pour les fichiers .png)

Aucun de ces programmes n’est obligatoire. Chacun n’est nécessaire que pour le type de fichier qu’il traite. Voir Extraction automatique du texte pour plus de détails.

Installer les programmes d’extraction

Sous Debian et Ubuntu, tous les programmes peuvent être installés avec :

apt install poppler-utils odt2txt docx2txt catdoc tesseract-ocr

tesseract-ocr n’installe que les données de langue anglaise. D’autres langues peuvent être installées avec les paquets tesseract-ocr-<lang> correspondants (par exemple tesseract-ocr-fra pour le français).

Les programmes sont recherchés dans le PATH de l’utilisateur qui exécute Omeka S (par exemple www-data), à l’aide de command -v. Si un programme est installé dans un emplacement non standard, assurez-vous que cet emplacement figure dans le PATH de cet utilisateur.

Installation

Installez le module comme n’importe quel autre module Omeka S. Voir Adding modules to Omeka S (en anglais).

L’installation du module crée une table de base de données nommée mediatext_representation. La désinstallation du module supprime cette table, et donc toutes les représentations textuelles.
