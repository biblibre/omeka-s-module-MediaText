Introduction

Media Text allows to manage media textual representations (transcriptions, translations, transliteration, …).

They can be imported from files, visualized, modified, and used in several ways (for display, search, …).

Features

  • Supported formats: plain text, ALTO

  • Resource page block rendering textual representation as plain text

  • Automated text extraction for .pdf, .odt., .docx, .doc and .png files

  • Integration with the Solr module (makes the text content searchable)

  • Text documents are compressed using zlib to save disk space

  • Public/private visibility for each textual representation

  • Batch removal and batch extraction of textual representations for items and media

  • Admin advanced search filter on the presence of textual representations

  • REST API, and extension points for other modules (formats, ingesters, extractors)
