Gérer les représentations textuelles

Les représentations textuelles se gèrent depuis les pages des médias de l’interface d’administration.

Consulter les représentations textuelles d’un média

Sur la page d’un média, un onglet nommé Représentations textuelles liste toutes les représentations textuelles du média, dans l’ordre. Pour chaque représentation, la liste affiche :

  • son titre, avec un lien vers la page de la représentation,

  • son type et son format,

  • la mention « Extraite automatiquement » si elle a été créée par un extracteur,

  • une icône « privé » si elle est privée.

Deux actions sont disponibles pour chaque représentation :

  • Modifier ouvre la page de modification de la représentation,

  • Détails ouvre une barre latérale avec l’ID, le type, le format, la source et le contenu de la représentation.

Page de la représentation

La page de la représentation affiche l’ID, le type, le format et la source de la représentation, ainsi que son contenu. Le contenu est affiché deux fois, côte à côte : tel qu’il est stocké (par exemple en XML ALTO), et converti en texte brut. Cela permet de vérifier ce qui sera affiché sur les pages publiques et indexé par les moteurs de recherche.

Ajouter des représentations textuelles

  1. Modifiez le média, puis cliquez sur l’onglet Représentations textuelles.

  2. Dans la barre latérale à droite, sous Importer une représentation textuelle, cliquez sur l’un des boutons suivants :

    • Zone de texte : saisissez ou collez le contenu directement dans un champ texte,

    • Charger : chargez un fichier contenant le contenu.

  3. Remplissez le formulaire qui apparaît :

    • Titre (obligatoire),

    • Type (obligatoire) : Transcription, Translittération, Traduction ou Autre,

    • Format (obligatoire) : Texte brut ou ALTO,

    • Contenu ou Charger le fichier selon la méthode choisie.

  4. Cliquez sur Enregistrer.

Plusieurs représentations peuvent être ajoutées en une seule fois en cliquant plusieurs fois sur les boutons. Une nouvelle représentation qui n’a pas encore été enregistrée peut être retirée avec son icône Retirer la représentation.

Avec Charger, le contenu du fichier est copié dans la base de données (le fichier lui-même n’est pas conservé) et le nom du fichier est enregistré comme source de la représentation.

Le contenu est validé en fonction de son format avant d’être enregistré (voir Formats). Si la validation échoue, un message d’erreur est affiché et le média n’est pas enregistré.

Extraire des représentations textuelles

La même barre latérale contient une section nommée Extraire une représentation textuelle du média. Elle liste les extracteurs capables de traiter le fichier du média. Cochez un ou plusieurs extracteurs et cliquez sur Enregistrer pour créer de nouvelles représentations textuelles à partir du fichier du média.

Voir Extraction automatique du texte pour plus de détails.

Réordonner les représentations textuelles

Sur la page de modification du média, faites glisser les représentations à l’aide de leur poignée, puis cliquez sur Enregistrer. Cet ordre est utilisé dans l’interface d’administration.

Modifier la visibilité

Sur la page de modification du média, cliquez sur l’icône de visibilité (Rendre privé / Rendre public) d’une représentation, puis cliquez sur Enregistrer. Voir Visibilité.

Modifier une représentation textuelle

Cliquez sur l’icône Modifier d’une représentation (depuis la page du média, la page de modification du média ou la page de la représentation). Le formulaire de modification permet de changer le titre, le type, le format et le contenu de la représentation.

Le contenu est validé en fonction du format sélectionné avant d’être enregistré.

Supprimer des représentations textuelles

Sur la page de modification du média, cliquez sur l’icône Supprimer d’une représentation. La représentation est marquée pour suppression, et peut être restaurée avec l’icône Restaurer tant que le média n’est pas enregistré. Elle est supprimée au clic sur Enregistrer.

Pour supprimer les représentations textuelles de nombreux médias à la fois, voir Modification par lot.

Droits d’accès

  • Tout le monde peut consulter les représentations textuelles, selon leur visibilité (voir Visibilité).

  • Les auteurs, relecteurs, éditeurs, administrateurs de site et administrateurs généraux peuvent créer, modifier et supprimer des représentations textuelles. Notez que, comme pour toute autre modification d’un média, ils doivent être autorisés à modifier le média.
