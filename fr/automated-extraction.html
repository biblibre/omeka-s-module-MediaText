Extraction automatique du texte

Media Text peut créer automatiquement des représentations textuelles en extrayant le texte des fichiers de médias, à l’aide de programmes externes appelés extracteurs.

Un extracteur est disponible si le programme correspondant est installé sur le serveur (voir Prérequis). Un extracteur ne peut être utilisé que sur des médias disposant d’un fichier original dont le type de média est pris en charge.

tesseract est un moteur d’OCR (reconnaissance optique de caractères). Il est exécuté avec ses paramètres par défaut, c’est-à-dire avec les données de langue anglaise.

Représentations extraites

Chaque extracteur crée une représentation textuelle avec les propriétés suivantes :

  • Titre : « Extrait par <extracteur> » (par exemple « Extrait par pdftotext »)

  • Type : Transcription

  • Format : Texte brut

  • Visibilité : Public

  • Source : la source du média (généralement le nom du fichier original, ou son URL)

  • Extraite automatiquement : oui

Les représentations extraites sont ajoutées après les représentations existantes du média. Elles peuvent être modifiées, réordonnées et supprimées comme n’importe quelle autre représentation.

L’extraction du texte d’un fichier de média est effectuée de manière synchrone, pendant l’enregistrement du média. Elle peut être lente pour les fichiers volumineux, en particulier avec tesseract.

Si les fichiers des médias ne sont pas stockés localement (par exemple avec un module qui stocke les fichiers sur Amazon S3), ils sont téléchargés dans un fichier temporaire avant l’extraction.

Quand l’extraction a-t-elle lieu ?

À la création d’un média

Lorsqu’un média est créé (par exemple lors de l’ajout d’un fichier à un contenu, ou pendant un import), tous les extracteurs disponibles qui prennent en charge le fichier du média sont exécutés automatiquement.

À la modification d’un média

Modifiez le média, cliquez sur l’onglet Représentations textuelles, puis dans la barre latérale, sous Extraire une représentation textuelle du média, cochez les extracteurs à utiliser. Cliquez ensuite sur Enregistrer.

Seuls les extracteurs qui prennent en charge le fichier du média sont listés. Les extracteurs dont le programme n’est pas installé sont listés mais désactivés, avec la mention « (non disponible) ».

L’extraction ne remplace pas les représentations existantes : exécuter deux fois le même extracteur crée deux représentations. Pour remplacer des représentations extraites, supprimez-les d’abord (voir Modification par lot).

Par lot

Les extracteurs peuvent être exécutés sur de nombreux contenus ou médias à la fois grâce au formulaire de modification par lot. Voir Modification par lot.
