Recherche

Recherche avancée (administration)

Media Text ajoute un champ nommé Recherche par présence de représentations textuelles au formulaire de recherche avancée des contenus et des médias dans l’interface d’administration. Il propose les options suivantes :

  • A des représentations textuelles : ne retourne que les contenus (ou médias) qui ont au moins une représentation textuelle (pour les contenus : au moins un média du contenu a une représentation textuelle),

  • N’a pas de représentations textuelles : ne retourne que les contenus (ou médias) sans aucune représentation textuelle.

Recherche plein texte avec Solr

Lorsque le module Solr (et le module Search dont il dépend) est installé, le contenu des représentations textuelles peut être indexé, ce qui le rend interrogeable.

Media Text ajoute un nouveau champ source au module Solr, sous Médias, nommé Contenu des représentations Media Text (texte brut). Il contient le contenu de toutes les représentations textuelles de tous les médias d’un contenu, converti en texte brut (voir Formats).

Pour l’utiliser :

  1. Allez dans la configuration du module Solr, et modifiez les correspondances (mappings) de l’index Solr pour les contenus.

  2. Ajoutez une nouvelle correspondance utilisant la source Médias › Contenu des représentations Media Text (texte brut), et choisissez un champ Solr adapté au plein texte (par exemple un champ *_txt).

  3. Réindexez les contenus.

Voir la documentation du module Solr pour plus de détails.

Note

Seuls les contenus sont pris en charge. Les représentations textuelles ne sont pas ajoutées aux médias indexés.

Note

Modifier une représentation textuelle depuis sa propre page de modification ne modifie ni le média ni le contenu : le changement n’est donc pas détecté par le module Search. Enregistrez le contenu (ou reconstruisez l’index) pour mettre à jour le texte indexé.
