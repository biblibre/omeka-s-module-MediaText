Représentations textuelles

Une représentation textuelle est une ressource rattachée à un média. Elle décrit le texte contenu dans le média (qu’il s’agisse d’une image, d’un PDF, d’une vidéo, d’un son ou de toute autre chose).

Elle sert principalement à stocker les transcriptions d’un média, mais peut aussi servir à stocker des traductions ou des translittérations.

Les représentations textuelles peuvent être stockées en texte brut ou en ALTO.

Un média peut avoir plusieurs représentations textuelles.

Propriétés

Chaque représentation textuelle possède les propriétés suivantes :

Titre

Un titre libre (obligatoire). Les représentations extraites automatiquement sont intitulées « Extrait par <extracteur> » (par exemple « Extrait par pdftotext »).

Type

Transcription, Translittération, Traduction ou Autre.

Format

Le format du contenu : Texte brut ou ALTO. Voir Formats.

Contenu

Le texte lui-même.

Visibilité

Public ou privé. Voir Visibilité.

Source

La provenance du contenu. Elle est définie automatiquement avec le nom du fichier chargé lors de l’utilisation de la méthode Charger, ou avec la source du média lorsque la représentation est extraite automatiquement.

Extraite automatiquement

Indique si la représentation a été créée par un extracteur (voir Extraction automatique du texte). Cela permet de supprimer par lot uniquement les représentations extraites (voir Modification par lot).

Position

L’ordre de la représentation parmi les représentations du média.

Créée / Modifiée

Date de création et date de dernière modification.

Formats

Texte brut

Tout texte est accepté. Le contenu est stocké et affiché tel quel.

ALTO

ALTO (Analyzed Layout and Text Object) est un format XML couramment produit par les logiciels d’OCR. Il contient le texte et sa position sur la page.

Lors de l’enregistrement d’une représentation ALTO, le module vérifie que :

  • le contenu n’est pas vide,

  • le contenu est un XML bien formé,

  • l’élément racine est alto,

  • l’élément racine possède un espace de noms (toutes les versions d’ALTO sont acceptées).

Si l’une de ces vérifications échoue, la représentation n’est pas enregistrée et une erreur est affichée.

Le module est capable de convertir l’ALTO en texte brut. Cette version en texte brut est utilisée pour l’affichage sur les pages publiques (voir Affichage public) et pour l’indexation (voir Recherche). Elle est construite comme suit :

  • chaque élément String d’une TextLine est remplacé par son attribut CONTENT, les éléments étant séparés par des espaces,

  • chaque TextLine est placée sur sa propre ligne,

  • chaque TextBlock est séparé du suivant par une ligne vide.

Visibilité

Chaque représentation textuelle peut être publique ou privée. Les nouvelles représentations sont publiques par défaut.

Une représentation textuelle est visible :

  • par les utilisateurs qui peuvent voir toutes les ressources (administrateurs généraux, administrateurs de site, éditeurs et relecteurs), quelle que soit sa visibilité,

  • par le propriétaire du média auquel elle est rattachée, quelle que soit sa visibilité,

  • par toute autre personne (y compris les visiteurs anonymes), si elle est publique et si le média auquel elle est rattachée leur est visible.

Autrement dit, une représentation publique d’un média privé n’est pas visible par le public.

Stockage

Le contenu des représentations textuelles est compressé dans la base de données avec zlib (format gzip) pour économiser l’espace disque. Le niveau de compression est configurable (voir Configuration).

Les représentations sont rattachées à un média : lorsqu’un média est supprimé, toutes ses représentations textuelles sont également supprimées.
